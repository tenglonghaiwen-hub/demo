## 4. Codex本体与目标架构验收条件（全部待实施/验证）
| 编号 | 必须观察到的通过条件 |

| C05 审批 | 绑定来源/会话/工作区/参数/目标/期限且一次性；拒绝、变化、过期、取消、进程换代后不能复用；模型approved字段无效 |

| C07 模型与秘密 | 用户中转实际支持所需流式/工具/取消/错误；不静默换供应商；凭据安全存储且不进入renderer/源码/日志/草稿 |
| C08 扩展能力 | 多Agent、持续任务、MCP、技能、插件、电脑/浏览器逐项真实验证发现、状态、归属、权限、停止及结果；不默认全部兼容 |
| C09 唯一执行链 | Codex原生操作只执行一次；宿主直接动作标明来源并同样受控；真实历史以运行时受支持协议为准 |
| C10 能力对齐 | 每项记录参考版本行为、核心复用/宿主补足、依赖限制、状态和证据；缺口不得静默删除或标完成 |
