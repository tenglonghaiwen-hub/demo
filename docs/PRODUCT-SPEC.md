# 产品功能与要求规范

版本：UI-001 候选基线，2026-09-28。产品名、技术栈、目录职责和前端布局尚待用户确认，不能称为冻结。

## 产品定位与本轮交付
独立 Windows 桌面 AI 助手，将编程、项目上下文、本机操作和视频工作集中在可观察、可审批的工作台。模型中转协议、视频供应商及 Codex 接入方式尚未确定；不承诺直接继承 Codex 的全部能力或第三方扩展兼容性。

UI-001 仅建立可运行外壳、模块导航和真实本地会话草稿。草稿不是已发出的 AI 消息，会话不是已启动的 Agent 任务。当前不发送模型请求、不执行终端或电脑操作、不安装插件、不生成视频。
技术栈、工程结构与前端布局、导航、基础组件和交互基线同步实施，在同一个 Windows 应用中集成验收、一起交付用户审阅；确认后一起冻结，不将界面推迟到另一轮。

| 功能域 | 目标能力与后续验收方向 | UI-001 边界 |
| --- | --- | --- |
| 编程工作台 | Codex 连接、流式消息、工具事件、取消与失败恢复；结果可追溯到实际执行 | 仅工作台入口与未接入状态 |
| 项目 | 选择目录、查看可信项目上下文、约束工作范围；文件读取与修改有边界 | 原生目录选择并保存路径，不扫描或修改项目 |
| 会话 | 创建、恢复、重命名、任务状态及历史；明确本地数据与远端会话关系 | 创建、切换、重命名、编辑和保存本地草稿 |
| 终端与差异 | 终端生命周期、命令输出、取消；查看修改前后差异及应用范围 | 展示待接入说明，无命令执行或 Git 写入 |
| 审批 | 绑定具体操作和参数的确认，拒绝与过期阻止执行，保留脱敏审计 | 仅说明边界，未实现审批器或执行器 |
| 电脑与浏览器 | 可观察目标、操作范围、截图/页面证据、停止；能力和权限按连接器核实 | 模块入口，未接入 |
| 视频与素材 | 素材登记、生成参数、提交审批、状态、下载与失败处理；原素材保留 | 模块入口，未上传、未生成 |
| 模型中转 | 协议、能力、地址配置、安全凭据、真实连通性与错误区分 | 模块入口，供应商未定，不索取密钥 |
| MCP | 服务配置、连接状态、工具发现、权限及调用记录 | 模块入口，未连接服务 |
| 插件与技能 | 来源、能力、权限、安装/卸载和启停，明确格式兼容范围 | 模块入口，未安装或调用 |

## 当前交互约定
- 目录选择取消返回原状态；成功只保存路径，不能解释为已获得该目录全部操作授权。
- 会话持久字段：ID、名称、草稿、关联项目路径、更新时间。名称 1–80 字符，草稿最多 20000 字符，最多 200 个草稿会话，以代码中的 `LIMITS` 为准。
- 保存状态必须区分未保存、正在保存、已保存和失败；只在持久化成功后显示已保存。切换和关闭期间不得默默丢失未保存输入。
- 重启可读回已保存会话；损坏或不可访问的数据须提示错误并保留原文件，不静默重置为空。
- 浏览器预览没有桌面桥时明确提示启动桌面版，并禁用需要桌面桥的操作。
- 未接入模块明确说明当前状态和依赖；不使用虚构的连通、任务进度、生成结果或测试成功。

## 安全、数据与质量要求
主界面不能直接访问 Node、文件系统、任意 IPC 或系统命令。后续执行统一经过能力边界；模型输出、网页、插件内容不能授予权限。危险操作审批须绑定操作参数与有效期，参数变化、过期或拒绝后不得复用批准。

删除须先列具体路径、数量和影响并等待确认；付款、注册、发送消息、账号权限修改执行前再次确认。付费视频生成遵循付款规则。UI-001 不提供上述执行入口。

本轮数据以明文 JSON 留在本项目 `.local/app/sessions.json`；不是凭据存储，用户不应在草稿中输入密钥。未来凭据采用系统安全存储并脱敏日志。安装包、签名、自动更新、云同步及多设备支持均不属于本轮承诺。

界面以中文为主，键盘可操作、焦点可见、错误可读；最小窗口尺寸内关键操作可达。验证须区分静态检查、构建、模拟和真实桌面行为，证据见 `ACCEPTANCE.md`。

## 后续独立功能拆分建议
以下为建议顺序，不表示已授权实施；正式 ID、范围和状态统一由 `TASKS.md` 管理，每项在新主会话执行。

| 候选任务 | 前置决策 | 最小可验收结果 |
| --- | --- | --- |
| 模型中转配置 | 协议与凭据保存方式 | 真实连接或具体失败原因；凭据不进入前端包和日志 |
| Codex 会话接入 | 官方协议能力及与中转兼容性 | 一次真实请求、流式事件、取消和恢复；不混淆本地草稿 |
| 项目上下文读取 | 路径及读取权限边界 | 仅授权范围内读取；越界拒绝并可观察 |
| 操作审批 | 操作类型、参数及有效期契约 | 同意/拒绝/过期/参数变化均有明确结果 |
| 终端执行 | 审批与进程管理 | 受控命令、输出、停止及进程退出可验证 |
| 文件差异 | 审批与文件写入边界 | 可审阅真实差异，批准后仅应用指定修改 |
| 浏览器控制 | 连接器和页面授权 | 指定页面只读观察，再分期实现有确认的操作 |
| 本机电脑控制 | Windows 能力与停止机制 | 目标窗口可观察、操作可中止，危险动作受审批 |
| 视频素材与生成 | 供应商协议和计费 | 先素材登记，再另项接入经确认的生成及结果获取 |
| MCP 管理 | 传输与工具权限策略 | 服务状态真实，工具调用有审计和审批边界 |
| 插件管理 / 技能管理 | 各自格式与权限契约 | 分项实现来源展示、启停、安装与卸载规则 |

骨架确认后，新增功能只能沿确认的扩展点实施；结构或布局变更先说明影响并取得用户批准。
